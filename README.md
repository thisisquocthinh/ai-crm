# AI CRM

Hộp thư gộp Fanpage Facebook + Zalo cá nhân, kèm nút gợi ý trả lời bằng AI dựa trên danh mục sản phẩm tự nhập. Dự án cá nhân.

Xem thiết kế: [docs/DESIGN.md](docs/DESIGN.md)

## Chạy thử giao diện trên máy

```bash
cd web
npm install
npm run dev
```

Mở http://localhost:3000. Hiện dùng dữ liệu giả, nút "Gợi ý AI" chưa gọi AI thật.

Muốn xem trên điện thoại cùng mạng Wi-Fi: `npm run dev -- -H 0.0.0.0` rồi mở `http://<IP-máy-tính>:3000`.
